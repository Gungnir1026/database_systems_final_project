## 本次交付

獨立建立 `scholarship-management-system/`，原有三個資料夾與各自 Git 紀錄保留原狀。新的 ZIP 僅包含整理版，不包含舊副本、舊 Git 歷史、已安裝相依套件或原始 `.env`。

保留 `ddbb` 的角色流程與功能頁面，移除四個已被取代的原型頁面：`main.html`、`stu_form.html`、`scholarship_provider.html`、`system_manager.html`。其中 `stu_form.html` 只有顯示成功 alert 的靜態表單，沒有真正送出申請；完整功能改由既有的 `stu_apply.html` 承接。最終版保留 31 個 HTML 頁面。

其餘修正包括學號／主鍵混用、註冊跨表寫入、公告作者缺失、固定 localhost API 網址、申請期間與重複申請、登入與權限、資料持久化及初始化方式。詳見 [變更紀錄](../CHANGELOG.md)。
