整合測試使用實際 MySQL，為每次測試建立獨立的隨機資料庫，完成後刪除。涵蓋：

- 四種角色登入、Cookie 屬性、所有列表與個人資料查詢。
- 禁止跨帳號讀取、越權編輯、偽造單位及公告作者、管理員自助註冊。
- 三種角色註冊與失敗時回復交易，密碼不以明文儲存。
- 獎學金發布、日期限制、重複申請阻擋、成績與排名驗證。
- 指定教師撰寫／修改推薦信、阻擋其他教師操作。
- 單位審核、學生查詢進度、管理員編輯與刪除。
- 跨資料表修改失敗時回復、外鍵連動刪除、偽造 query-string 帳號不影響操作目標。
- 修改密碼撤銷 sessions、過期與登出後無法存取 API。
- 跨來源寫入及非 JSON 請求阻擋。

瀏覽器測試以真正的登入頁操作四種角色，逐一開啟側欄頁面，確認學號、申請詳情、推薦信、結果公告草稿與登出。另檢查手機寬度登入，以及含引號和 HTML 字元的公告是否以文字顯示並可正確開啟編輯。

`docs/screenshots/` 的 6 張 PNG 均由執行中的展示版實際擷取，管理員、學生與結果畫面另經目視檢查。

GitHub Actions 設定已備妥，但本次沒有將專案推送至 GitHub，因此沒有遠端 CI 執行紀錄。phpMyAdmin 為可選服務，本次驗證使用應用程式及 MySQL 連線，未另啟動 phpMyAdmin。

驗證結束後已移除本次獨立建立的測試容器與測試 volume；依 README 執行 Docker Compose 即可從初始展示資料啟動。
